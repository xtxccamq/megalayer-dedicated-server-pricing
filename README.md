## 同一台 E3-1230 为什么有三个价

把 Megalayer 的公开数字摆在一起看：

四个数字对应四种口径，差异主要来自三处：

**活动款与常规款。** 199 那一档是限时秒杀，卖完即止，且需要在下单时命中活动机型。常规页面上的价格是 499 一档。

**带宽类型。** 同一台机器可以选 10M 优化、15M 全向或 20M 国际，三种线路的成本不同，报价自然不同。有些资料只写"香港 E3-1230"，把线路省掉了，价格就没法比。

**IP 数量与产品线。** 普通独服默认 3 个 IPv4，站群产品是 5 个普通 IP 加 125 个站群 IP（1C 段）这种量级，两者不是一类东西。有推广文写"默认 2 个 IPv4"，与官网产品页和其他测评站的 3 个不一致，下单前按订单页确认。

美国机房还有一处口径分歧：多数资料写圣何塞，也有测评站写洛杉矶。如果你对机房位置有硬性要求，下单前问清楚具体是哪个数据中心。

## 默认 3 个 IP，站群是另一条产品线

Megalayer 官方英文产品页对普通独立服务器统一标注 3 IP，多家第三方测评站的说法一致。这 3 个 IP 是包含在月费里的，需要更多可以单独加购。

这里最容易踩的坑是拿站群价去比普通独服价，然后把普通独服说成"贵"。反过来也一样。

## 优化、全向、国际：三条线路怎么选

Megalayer 官方对三种带宽的定义是这样的：

**大陆优化带宽**包含中国三大运营商与机房直连的最优质线路，同时包含访问国际及机房本地的路由，官方说法是"可以最大限度保证全球用户访问机房的线路可用性及访问质量"。

**全向带宽**包含三大运营商与机房连接的普通线路，也包含国际及本地路由，但访问质量受线路拥挤影响，高峰期"不能完全保证一致的访问质量"。

**国际带宽**只覆盖机房本地及国际方向，不包含三大运营商与机房的直连路由，大陆访问"有可能会绕道第三地，所以延迟和丢包率均无法保障"。

香港优化线路的实际路由，第三方测评做过去回程测试，电信去程和回程都走 59.43 节点，也就是 CN2 GIA。晚高峰测试的结论是亚洲及大陆延迟较低、丢包可以接受。这类数据属于第三方测评结果，不同时间段会有波动，只能作为参考。

带宽上限方面，优化带宽最高可扩到 100M，国际带宽能到 300M。香港优化线路的起步带宽是 10M。

按需求对号入座：

面向大陆用户建站，选优化带宽。10M 看着小，但 CN2 线路的实际体验比 30M 国际线路好，这是线路质量决定的，不是带宽数字决定的。

纯海外用户或大流量下载站，选国际带宽。绕路带来的延迟对这类业务影响小，带宽给得大才是关键。

预算优先、能接受晚高峰波动，选全向带宽。它是优化和国际之间的折中，去程可能走 CN2，回程走普通线路。
